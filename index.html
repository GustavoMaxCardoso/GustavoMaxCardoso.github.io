Projetos

Sistemas que escrevi para resolver problemas reais da rede. Os dois primeiros estão em uso e têm código aberto no GitHub.

HUB Fazfarma

Portal interno que reúne as ferramentas das lojas num login só. Cada pessoa vê apenas o que o perfil dela permite, e as ferramentas integradas abrem já autenticadas.

  • Permissões por perfil conferidas no servidor em todas as rotas
  • Senhas com Argon2id, sessão em cookie httpOnly assinado e limite de tentativas no login
  • Login único (SSO) com token assinado para as ferramentas integradas
  • Trilha de auditoria e mural de avisos com controle de leitura
  • FastAPI
  • PostgreSQL
  • SQLAlchemy
  • React
  • Tailwind
  • Nginx
  • Docker Compose

FarmaCompare

Comparador de preços de medicamentos usado pelas lojas. Consulta várias fontes ao mesmo tempo, com limite de tempo por fonte, e mostra o que chegou mesmo quando alguma falha. Guarda histórico, avisa variações de preço e consulta a tabela oficial da CMED/Anvisa.

  • Python
  • Flask
  • SQLite
  • ThreadPoolExecutor
Ver o código no GitHub

Digitalizador Farmácias

Reescrevi em Python, por engenharia reversa, o programa que as lojas usam para digitalizar documentos. A nova versão mantém exatamente o padrão de pastas e nomes que a operação exige e roda como executável nas máquinas das lojas.

  • Python
  • PyInstaller
  • Integração com scanner

Monitoramento da rede

Implantei o monitoramento dos links, dos 10 servidores e dos gateways de todas as unidades, numa rede com mais de 200 dispositivos. Os alertas avisam quando algo cai ou degrada, muitas vezes antes de a loja perceber.

  • Zabbix
  • Grafana

Migração da rede central

Conduzi a troca dos roteadores MikroTik por gateways Ubiquiti, com VPN entre as cidades, bloqueio de acesso por região e separação das redes Wi-Fi de clientes e funcionários.

  • UniFi
